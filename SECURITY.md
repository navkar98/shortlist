# Security policy

Shortlist runs on your own computer with your API keys, bot token, and resume. If you find a way it could leak them,
make the web app reachable by others, or otherwise put its users at risk, please report it privately: use **Report a
vulnerability** on the repository's **Security** tab instead of opening a public issue.

Include what you found, how to reproduce it, and the commit you used. Fixes land as new commits on `main`, which is
the only supported version.
